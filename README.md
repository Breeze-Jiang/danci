## 应用形式
- 后台管理系统
- h5应用
- 多端开发
## 亮点
- 数据清洗
github 高星的单词资料库
之后要对这个资料库进行清洗（选择，格式化，审核）
- supabase 云端的psql数据库
  关系型数据库
- ORM 不用写sql，不用做数据库的底层处理
  对象关系映射
  todo.save() 表示将todo对象保存到数据库中
  对象和数据库一行记录 对应起来
